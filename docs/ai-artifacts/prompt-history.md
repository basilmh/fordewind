# История промптов ИИ

1. Проверить текущую инфраструктуру и локальную конфигурацию. Исходная информация в README.md. Обновить ридми при необходимости
2. Реализовать консольную команду импорта: получать исходные данные из `https://gitlab.fdw.ru/ext/test_task` по пути из config/env, обрабатывать JSON и добавлять данные в БД без публикации изображений на этом этапе.
3. Добавить в skill миграций проверку применимости через `canRunMigration()` и применить это правило к текущим миграциям.
4. Добавить в README ссылки на настройки ИИ-агента и project-specific skills.
5. Обновить skill тестов: использовать `camelCase`, `TestDox` и private helpers для fixture-данных; применить правила к текущим тестам.
6. Для `cars` типизировать `custom_status` enum-ом.
7. Ввести value object `Money` на `BigDecimal` с валютой USD по умолчанию для денежных полей автомобилей.
8. Не прерывать импорт из-за ошибки одного исходного файла: пропускать проблемную запись и продолжать обработку остальных.
9. Реализовать потоковый импорт с generator, configurable чанками и batch `upsert` для неизвестных объёмов данных.
10. Сделать импорт устойчивым к ошибке DB batch: повторять batch и изолировать проблемную запись без остановки следующих чанков.
11. По ревью: отклонять дубли `AuctionItemId`, публиковать изображения только после сохранения записи, завершать полностью невалидный импорт с ошибкой.
