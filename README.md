# Fordewind

Веб-приложение на Laravel для попарного голосования за фотографии аукционных автомобилей и просмотра статистики голосования.

## Задача

Необходимо реализовать две независимые клиентские области:

- **Голосование:** пользователь выбирает модель автомобиля, получает две разные случайные фотографии и голосует за одну из них. Пары загружаются через jQuery/AJAX без перезагрузки страницы; фотографии увеличиваются с помощью jQuery ezPlus в режиме Tints.
- **Статистика:** Vue.js отображает автомобили и число голосов, позволяет фильтровать результаты по модели и диапазону годов выпуска, а также показывает суммарное число голосов для выбранных фильтров.


## Стек

- PHP 8.3 и Laravel 12;
- MySQL 8.4 для разработки и отдельная MySQL БД для PHPUnit;
- Nginx и PHP-FPM в Docker Compose;
- Vue 3 для статистики;
- jQuery 3 и ezPlus для страницы голосования;
- Vite 7 для frontend-сборки;
- Task для единых локальных команд.

## Требования

- Docker Engine с Docker Compose v2;
- Для быстрого запуска нужно установить [Task](https://taskfile.dev/);
- свободный порт по умолчанию `8082` для приложения и `33063` для MySQL.

## Быстрый старт

```bash
cp .env.example .env
task init
```

`task init` создаёт runtime-директории, поднимает контейнеры, устанавливает Composer/npm-зависимости, генерирует `APP_KEY`, применяет миграции, создаёт `storage` symlink и собирает frontend.

После успешной инициализации приложение доступно по адресу [http://localhost:8082](http://localhost:8082).

Справочник доступных Task команд: [docs/commands.md](docs/commands.md).

## Локальная конфигурация

В `.env` можно изменить:

- `APP_PORT` - внешний HTTP-порт, по умолчанию `8082`;
- `FORWARD_DB_PORT` - внешний порт dev MySQL, по умолчанию `33063`;
- `USER_ID` и `GROUP_ID` - UID/GID пользователя хоста. Значения по умолчанию `1000` подходят для стандартного Linux-окружения;
- `DB_*` - подключение к основной dev БД;
- `DB_TEST_*` - подключение к изолированной БД тестов.
- `CARS_IMPORT_REPOSITORY` - URL Git-репозитория с исходными JSON;
- `CARS_IMPORT_SOURCE_PATH` - каталог, в который `task import` клонирует репозиторий и из которого читает JSON.
- `CARS_IMPORT_BATCH_SIZE` - размер чанка импорта, по умолчанию `200`;
- `CARS_IMPORT_IMAGES_PATH` - каталог JPG-изображений в источнике; если не задан, используется `CARS_IMPORT_SOURCE_PATH`;
- `CARS_PUBLIC_IMAGES_PATH` - каталог назначения изображений в `public`;

Не добавляйте `.env` в Git. Шаблон содержит только локальные значения разработки без реальных секретов.

## Сервисы Docker

| Сервис | Назначение |
| --- | --- |
| `nginx` | HTTP-сервер на `APP_PORT` |
| `app` | PHP 8.3 FPM, Artisan и Composer |
| `mysql` | Основная dev MySQL БД |
| `mysql-test` | Изолированная MySQL БД для PHPUnit |
| `frontend` | Node 22 для npm, Vite и frontend-сборки |


## Frontend

Vue 3 подключён через `@vitejs/plugin-vue`. Отдельные entry points размещаются в `resources/js`:

- jQuery и ezPlus используются только для области голосования;
- Vue используется только для статистики.

Сборка frontend проверяется командой `task build`.
